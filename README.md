# lee-espanol

A personal reading-practice project for Russian-native, A1-level Spanish
learners. Short, atmospheric sci-fi stories in a shared "Space Expansion"
universe — slow contemplative pace, observer-protagonists, moral dilemmas, no
moralizing.

Each story is a single HTML page with hover popups on every meaningful word:
Russian translation, part of speech, lemma, and (when non-obvious) a short
grammar note. Click any word to open it in spanishdict.com.

## What's inside

```
lee-espanol/
├── index.html           ← table of contents (Pages landing page, generated)
├── vocabulario.html     ← corpus-wide vocabulary with links back to stories (generated)
├── profile.md           ← reader profile (taste, level, format choices)
├── lore.md              ← universe continuity: characters, places, terms, per-story deltas
├── CLAUDE.md            ← short guide for coding agents
├── .claude/skills/lee-story-pipeline/  ← one-command "new story" skill (runs the steps)
├── .ai/
│   ├── skills/          ← step skills (story → enrich → render) + render.py
│   ├── archetypes.jsonl ← design log per story (avoids repeats, gives index accents)
│   └── stories-index.json ← index cache (generated)
├── tests/               ← stdlib unittest suite for render.py
└── stories/
    ├── 01-saturn-ai/
    ├── …
    └── 25-un-litro/
        ├── story.md         ← pure Spanish text + frontmatter
        ├── enrichment.toml  ← per-word data, sentence translations
        └── index.html       ← bespoke render with hover popups
```

## How this was made

Built from the [language-reader-blueprint](https://github.com/usukololgubu/language-reader-blueprint)
recipe — a single-file instruction set for spinning up a similar reader for any
(native, target) language pair. An AI agent reads the blueprint, runs an
interview, scaffolds the project, and generates stories on demand.

## Status

Personal project. Stories are written for one reader's taste; I publish them in
case they're useful to other RU→ES A1 learners, but this is not a curated
product.

## Development

Python 3.11+, stdlib only. Commands below use `py` (Windows); on Linux/macOS use
`python3`.

- New story: the `lee-story-pipeline` skill (`.claude/skills/lee-story-pipeline/`).
- Tests: `py -m unittest discover tests -v`. The centerpiece re-renders a copy of
  every story and checks the result is byte-identical to the on-disk page.
- Before committing story changes: `py .ai/skills/render/render.py --lint`
  (coverage/consistency checks, must exit 0) and the tests. After re-enriching,
  `render.py --refresh-all` re-applies enrichment to every story, then rebuilds
  `index.html` and `vocabulario.html`.
- `index.html`, `vocabulario.html`, `.ai/stories-index.json` and the popup blocks
  inside story pages are generated by `render.py`; don't hand-edit them.
