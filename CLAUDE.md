# lee-espanol

Spanish A1 reading stories for one Russian-speaking reader. See README.md.

- **New story**: use the `lee-story-pipeline` skill (`.claude/skills/lee-story-pipeline/`).
  It chains the step skills in `.ai/skills/` (story → enrich → render).
- **Python**: docs say `py` (Windows). On Linux/macOS use `python3`. Stdlib only, 3.11+.
- **Checks before any commit touching stories**: `render.py --lint` and
  `python3 -m unittest discover tests`.
- `index.html`, `vocabulario.html`, `.ai/stories-index.json` and the popup blocks inside
  story pages are generated by `render.py`; don't hand-edit them.
- The user talks in Russian; repo text (docs, commits) stays in English.
